<Note>
This is an unofficial OpenAPI description of the U.S. Census Bureau's Census Data API, created from the [Census Data API User Guide (PDF, July 30, 2024)](https://www.census.gov/content/dam/Census/data/developers/api-user-guide/api-user-guide.pdf). It is not affiliated with or endorsed by the U.S. Census Bureau.
</Note>

The Census Data API gives the public access to raw statistical data from Census Bureau data programs. The data is usually tied to a geographic area (identified by a FIPS code) and a vintage (reference year).

## Base URL

`https://api.census.gov/data`
